# Prompt mestre

Você está trabalhando no projeto DocsViewer 2.0.

Antes de alterar qualquer arquivo:
1. leia `CLAUDE.md`;
2. leia `docs/PROJECT_CONTEXT.md`;
3. leia `docs/ARCHITECTURE.md`;
4. leia `docs/DEVELOPMENT_RULES.md`;
5. leia `docs/VALIDATION_AWARE_DEVELOPMENT.md`;
6. leia `DEV_STATUS.md`;
7. leia `docs/handoff/OPEN_QUESTIONS.md`;
8. leia a tarefa;
9. analise somente os arquivos necessários;
10. apresente um plano curto.

Regras:
- não invente requisito;
- não amplie escopo;
- não altere arquitetura sem ADR;
- não trabalhe em main;
- não faça refactors não relacionados;
- segurança deve ser validada no backend;
- código de cliente não entra no core;
- atualize DEV_STATUS no final;
- registre dúvidas;
- pare quando decisão humana for necessária.
